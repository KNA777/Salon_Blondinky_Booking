# Salon Booking — описание продукта для владельца

## Что это

**Salon Booking** — система онлайн-записи клиентов в салон красоты. Клиенты сами
выбирают услугу, мастера, дату и свободное время, а салон видит и управляет всеми
записями. Работает через два канала: **Telegram-бота** и **Mini App внутри Telegram**.

Никаких отдельных приложений устанавливать клиенту не нужно — всё происходит внутри
Telegram, к которому люди уже привыкли.

---

## Как это выглядит для клиента

### Через Telegram-бота

1. Клиент пишет боту салона и нажимает `/start`.
2. Бот предлагает выбрать услугу (маникюр, стрижка и т.п.) — кнопками, с ценой и
   длительностью.
3. Затем — мастера, который оказывает эту услугу.
4. Затем — удобную дату (до 7 дней вперёд).
5. Затем — свободное время (готовые слоты, занятые исключены).
6. Клиент подтверждает выбор — и запись создана. Бот показывает подтверждение.

Кнопки «Назад» и «Отмена» позволяют в любой момент вернуться или прервать запись.
За 24 часа и за 2 часа до визита бот сам пришлёт напоминание.

### Через Mini App (окно внутри Telegram)

Тот же сценарий, но в виде страницы в окне Telegram: клиент выбирает услугу → мастера →
дату → слот и записывается. Авторизация происходит автоматически по аккаунту Telegram —
пароль не нужен.

---

## Как это выглядит для администратора салона

Администратор управляет всем через тот же API (и в перспективе — через панель):

- **Услуги**: создание, изменение цены/длительности, скрытие (неактивные услуги не
  показываются клиентам).
- **Мастера**: добавление, указание, какие услуги мастер оказывает, рабочие часы по
  дням недели, активация/деактивация.
- **Записи**: просмотр расписания на день, подтверждение записи, отмена, отметка
  «не пришёл» (no-show), перенос на другое время, завершение.
- **Клиенты**: просмотр списка (имя, телефон) — только у администратора.

### Статусы записи

| Статус | Что значит |
| --- | --- |
| `created` | запись создана, ожидает подтверждения |
| `confirmed` | администратор подтвердил |
| `completed` | услуга оказана |
| `no_show` | клиент не пришёл |
| `cancelled` | запись отменена |

Переходы между статусами контролируются правилами (например, завершённую запись нельзя
вернуть в «создана»), чтобы исключить ошибки учёта.

## Что продукт умеет уже сейчас

- Полный цикл записи через бота и Mini App.
- Расчёт свободных слотов с учётом рабочих часов мастера и уже существующих записей.
- Защита от двойной записи (два клиента не займут одно время).
- Работа с часовыми поясами: всё хранится в UTC, показывается во времени салона.
- Напоминания клиентам за 24 часа и за 2 часа.
- Аутентификация клиентов и администраторов (пароли + вход по Telegram).
- Разграничение прав: клиент управляет только своими записями, администратор — всеми.
- Автодокументация API (Swagger) по адресу `/docs`.

## Что ещё можно добавить (по желанию)

- **Онлайн-предоплата** (Telegram Payments / ЮKassa) — бронь закрепляется оплатой.
- **AI-ассистент** — запись «человеческим языком» («хочу маникюр в субботу после
  обеда») и ответы на вопросы об услугах и ценах.
- **Голосовые сообщения** — клиент записывается голосом.
- **Рекомендации повторного визита** — «пора повторить окрашивание».

## Что нужно, чтобы запустить

1. **Сервер** (VPS) с Docker — у вас его пока нет, код полностью готов к деплою.
2. **Домен** (например, `salon.example.com`) — для HTTPS через Caddy.
3. **Telegram-бот** — токен от [@BotFather](https://t.me/BotFather).
4. **Переменные окружения** — доступы к БД, ключ JWT, токен бота (см. `.env.example`).

Запуск на сервере:

```bash
docker compose -f docker-compose.prod.yml --env-file .env.prod up -d --build
```

Подробности развёртывания и меры безопасности — в `README.md` и `SECURITY.md`.
